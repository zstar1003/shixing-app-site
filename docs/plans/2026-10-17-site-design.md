# 拾形 identity and support site

**English** | [繁體中文](2026-10-17-site-design.zh-TW.md)

The owner delegated a literary two-character name and authorized a public GitHub Pages support/privacy repository. 拾形 means gathering a form. It describes capture without promising exact reproduction; 留形 was more literal, while 物语 was less specific to 3D capture. The App Store name has been saved successfully. Bundle and project identifiers remain unchanged.

Use a small static site with a warm paper background, dark green typography, restrained red accents and a labeled abstract illustration. An existing blog would mix unrelated content, while a framework adds unnecessary dependencies; plain HTML/CSS makes these long-lived policy URLs easier to maintain. The site has a landing page, practical support page and dated privacy policy. All product copy is Simplified Chinese. Technical documentation has English and Traditional Chinese counterparts.

Publish only the authorized support email. Review phone/name belong in App Store Connect, not this repository. Explain local capture, optional depth, export, cache deletion, OS backups, voluntary support emails and GitHub hosting separately. Do not promise guaranteed reconstruction or show private scans. No analytics, remote fonts, scripts, upload form or cookies are added.

Validate semantic links, responsive layout, keyboard focus, content accuracy and the deployed HTTPS URLs. App Store privacy publication follows the owner's explicit confirmation; paid agreements remain deferred.
