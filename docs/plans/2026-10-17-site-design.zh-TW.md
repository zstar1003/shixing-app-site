# 拾形名稱與支援網站

[English](2026-10-17-site-design.md) | **繁體中文**

使用者委託選擇文藝的兩字名稱，並授權建立公開 GitHub Pages 支援與隱私儲存庫。「拾形」表示拾取形態，傳達採集而不承諾精確重現；「留形」較直白，「物語」則較難聯想到三維採集。App Store 名稱已成功儲存。套件與專案識別碼維持不變。

採用暖紙色背景、深綠文字、少量紅色點綴及標示為示意圖的抽象插畫。既有部落格會混入無關內容，框架則增加不必要的相依性；純 HTML/CSS 更容易維護長期有效的政策網址。網站包含首頁、實用支援頁及註明日期的隱私政策。產品文字為簡體中文，技術文件提供英文及繁體中文。

僅公開已授權的客服信箱。審查電話與姓名僅填入 App Store Connect。分別說明本機採集、選用深度、匯出、快取刪除、系統備份、主動寄送的支援郵件，以及 GitHub 託管。不得保證重建成功或展示私人掃描。不加入分析、遠端字型、腳本、上傳表單或 Cookie。

驗證語意連結、響應式排版、鍵盤焦點、內容正確性與已部署的 HTTPS 網址。App Store 隱私發布依使用者明確同意執行，付費協議延後處理。
